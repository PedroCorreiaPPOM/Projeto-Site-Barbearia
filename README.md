# GEO'ROCHA BARBEARIA

Site institucional desenvolvido para a GEO'ROCHA BARBEARIA, com foco em apresentar a barbearia, seus profissionais e facilitar o contato e o agendamento dos clientes.

## ✂️ Sobre o projeto

O projeto foi desenvolvido com uma abordagem moderna, responsiva e mobile-first, buscando proporcionar uma experiência simples e elegante para os clientes da barbearia.

O site apresenta:

- Apresentação da GEO'ROCHA BARBEARIA
- Galeria de cortes
- Informações sobre os barbeiros
- Horários de funcionamento
- Localização e contato
- Agendamento pelo WhatsApp
- Interface adaptada para celulares, tablets e computadores

## 👨‍💈 Barbeiros

- Geovane
- Daniel

## 📅 Agendamento

O cliente pode selecionar:

- Nome
- Data
- Horário
- Barbeiro

Após preencher os dados, o agendamento é encaminhado diretamente pelo WhatsApp do barbeiro selecionado.

> O horário é confirmado pelo barbeiro através do WhatsApp.
